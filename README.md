# 북스캔 (BookScan)

갤럭시 탭 S9+용 책·문서 스캐너. vFlat처럼 카메라에 비추면 종이를 찾아 그 크기대로 잘라서 이미지/PDF로 저장합니다.

## 기능
- **종이 자동 인식**: 미리보기에서 종이 테두리를 실시간으로 표시
- **원근 펴기 + 실제 비율 측정**: 카메라 초점거리로 종이의 진짜 가로세로 비율을 계산해 비스듬히 찍어도 반듯하게 펴줌. A4·B5, 레터, 신국판 비율이면 정확히 맞춤
- **자동 촬영**: 종이를 잠깐 가만히 두면 저절로 찍고, 페이지를 넘기면 다음 장을 또 찍음 (볼륨 키로도 촬영)
- **두 쪽 펼침 모드**: 펼친 책을 한 번에 찍어 가운데 접힌 곳을 찾아 두 쪽으로 나눔 (오른쪽부터 읽는 책도 지원)
- **인쇄용 보정**: 그림자·누런 종이색을 지우고 바탕은 하얗게, 글자는 진하게 → 일반 용지에 인쇄해도 사진이 아니라 문서 파일을 인쇄한 것처럼 나옴
  - 인쇄용 흑백 / 인쇄용 컬러(형광펜·색 글씨 유지) / 완전 흑백 / 선명하게 / 회색조 / 원본, 진하기 조절
- **자르기 편집**: 모서리·변을 끌어서 조정 (돋보기 표시), 자동 감지 다시 하기, 회전
- **PDF 저장**: 자동(스캔 종이 비율)·A4·B5·A5·Letter, 화질 150/200/300dpi → `문서/BookScan`
- **이미지 저장**: `Pictures/BookScan/문서이름`
- **인쇄**: 안드로이드 인쇄 화면으로 바로 인쇄
- **글자 인식(OCR)**: 한국어+영어, 인터넷 없이 기기 안에서. 줄을 누르면 그 줄만 복사, 전체 복사, 모든 쪽 합치기, TXT 저장
- 갤러리 사진 가져오기, 쪽 순서 바꾸기·삭제, 모든 쪽 보정 한 번에 바꾸기

## APK 만들기
`bookscan.yml` 한 파일만 GitHub 저장소의 `.github/workflows/` 에 넣으면 Actions가 APK를 만듭니다.
항상 같은 서명 키(`app/bookscan.jks`)로 빌드되므로 새 버전을 설치해도 기존 스캔이 유지됩니다.
