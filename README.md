# Galaxy StandBy Pro

삼성 갤럭시에서 아이폰 StandBy처럼 쓰는 충전 중 탁상 시계 앱입니다.
Kotlin · Jetpack Compose · MVVM + StateFlow · DataStore · DreamService · Media3.

- 패키지명: `com.galaxy.standbypro`
- 최소 Android 8.0 (API 26), 대상 Android 15 (API 35)
- 루팅 불필요, 시계는 인터넷 없이 동작

---

## 2. APK 만들기 — GitHub Actions (Android Studio 없이, 폰/태블릿 브라우저로 가능)

이 프로젝트에는 `.github/workflows/build-apk.yml`이 들어 있어 GitHub에 올리기만 하면 자동으로 빌드됩니다.

1. GitHub에서 새 저장소(비공개 가능)를 만들거나 기존 저장소에 새 브랜치를 만듭니다.
2. ZIP을 풀고 **안의 파일 전체를 저장소 최상위에** 올립니다.
   `.github` 폴더(점으로 시작, 숨김 폴더)도 반드시 함께 올라가야 합니다.
3. 저장소의 **Actions** 탭 → `Build APK` 실행 확인 (올리면 자동 시작, 5~10분).
4. 끝나면 저장소 오른쪽 **Releases** → `Galaxy StandBy Pro 빌드 N` → `GalaxyStandByPro-debug.apk`를 폰에서 바로 받습니다.
   (Actions 실행 화면 아래 Artifacts에도 ZIP으로 올라갑니다.)

빌드가 실패하면 Actions의 빨간 단계를 열어 오류 부분을 복사해 Claude에게 보내 주세요.

> 서명 키(`app/standby-debug.keystore`)가 저장소에 들어 있어서, 새로 빌드한 APK를 기존 앱 위에 그대로 덮어 설치할 수 있습니다.

### PC에서 직접 빌드 (선택)
Android Studio로 폴더를 열고 ▶ 실행하거나, 터미널에서:
```
./gradlew assembleDebug
```
결과물: `app/build/outputs/apk/debug/app-debug.apk`

## 3. 갤럭시에 설치

1. APK를 받아 파일을 엽니다 → "출처를 알 수 없는 앱 설치"를 브라우저/내 파일에 허용.
2. 설치 후 앱 서랍에 아이콘이 2개 생깁니다.
   - **Galaxy StandBy Pro**: 설정·권한 화면
   - **StandBy 시작**: 바로 전체 화면 실행 (삼성 루틴에서 고르기 쉬움)

ADB로 설치: `adb install -r GalaxyStandByPro-debug.apk`

## 4. 처음 설정 (중요)

### ① 충전 중 자동 표시 — 화면 보호기 (가장 확실)
설정 > 디스플레이 > **화면 보호기** > `Galaxy StandBy Pro` 선택 → 시작 시점 **충전 중**.
충전 중 화면이 자동으로 꺼질 시점에 StandBy가 나타납니다. (앱 안 '화면 보호기 설정 열기'로 바로 이동)

### ② 다른 앱 음악 표시 — 알림 접근
앱 > 준비 상태 > **음악 정보 (알림 접근)** → Galaxy StandBy Pro 허용.
직접 설치한 APK라 회색으로 막혀 있으면: **앱 정보 열기 → 오른쪽 위 ⋮ → '제한된 설정 허용'** 후 다시 시도.

### ③ (선택) 충전 연결 + 가로로 놓으면 바로 실행
자동 실행 > `충전 연결 시 자동 실행 (실험)` 켜기 → `다른 앱 위에 표시` 허용.
허용하지 않으면 알림으로만 안내합니다.

### ④ (선택) 삼성 모드 및 루틴
조건 `충전 상태: 충전 중` (+ 원하면 화면 방향) → 동작 `앱 열기: StandBy 시작`.

> Android 보안 정책상 일반 앱이 충전기 연결만으로 잠금 화면 위에 **항상** 자동 실행된다고 보장할 수는 없습니다. 이 앱은 권한 우회나 접근성 권한을 쓰지 않습니다.

## 5. 기능

### 네 가지 화면 (좌우 스와이프)
- **위젯**: 좌우 2분할 스택(기본 왼쪽 아날로그 시계 / 오른쪽 월간 달력). 각 스택을 위아래로 밀어 변경, 길게 눌러 편집(순서·종류·너비·강조색).
  위젯 10종: 디지털 시계, 아날로그 시계, 달력, 오늘 날짜, 세계 시계, 배터리, 충전 상태(W·전류·전압·온도·완충 예상), 날씨, 재생 중인 음악, 일정
- **시계**: 위아래로 밀어 6가지 스타일 — 거대한 디지털 / 미니멀 아날로그 / 클래식 아날로그 / 컬러 디지털 / 세계 시계 / OLED 미니멀. 12·24시간, 색상, 초침, 날짜 설정.
- **사진**: 사진·폴더(앨범) 선택, 자동 슬라이드쇼, 크로스페이드, 채우기/맞춤, 사진 위 시계·날짜, 위아래 스와이프로 넘기기.
- **음악**: 왼쪽 큰 앨범 커버(둥근 모서리·커버 색 글로우), 오른쪽 제목·가수·앨범·진행 바·시간·이전/재생/다음. 커버 색 그라데이션, 곡 전환 크로스페이드, 탭하면 커버 크게 보기.

### 음악 연동
- 외부 앱: `MediaSessionManager` + `MediaController` (알림 접근 권한). Spotify, YouTube Music, Samsung Music, Apple Music 등 표준 MediaSession 앱.
  커버는 `METADATA_KEY_ALBUM_ART → ART → (DISPLAY_ICON) → ALBUM_ART_URI → ART_URI` 순으로 사용.
  세션이 허용한 명령(PlaybackState.actions)만 버튼 활성화, 나머지는 흐리게 비활성화.
- 내부 플레이어: Media3 ExoPlayer + MediaSessionService. 파일/폴더 추가(SAF), 재생목록(순서 변경·삭제), 셔플, 반복, 탐색, 시스템 미디어 알림·잠금화면 컨트롤 연동. 커버는 파일 내장 이미지(MediaMetadataRetriever).
- 커버는 최대 768px로 줄여 메모리 사용 제한, 로딩 중엔 이전 커버를 유지해 깜빡임 방지.
- 잠금 화면에서 곡 정보 숨기기 옵션.

### OLED 번인 방지
- 시계·날짜·위젯·커버·버튼·진행 바를 각각 다른 방향으로 1~3분(설정 가능)마다 이동. 매번 중심 기준 절대 위치로 계산해 한쪽으로 밀리지 않음. 화면 크기의 3% 이내로 제한하고 같은 크기의 여백을 둬 잘림 없음. 부드럽게/즉시 선택.
- OLED 보호 모드(흰 요소 밝기 감소), 유휴 시 어둡게, 자동 화면 끄기, 커버 밝기·자동 축소·숨기기, 일정 시간 후 음악 → 시계 전환, 야간 밝기.
- 밝기 조절은 앱 창에만 적용, 시스템 밝기 설정은 바꾸지 않음.
- 번인 가능성을 줄일 뿐 완전히 막는다고 보장하지 않습니다.

### 야간 모드
붉은 단색 숫자·바늘·위젯, 커버/사진 붉은 필터, 낮은 밝기, 애니메이션 축소. 자동(조도 센서 → 없으면 시간대) / 항상 / 끄기. '야간에는 시계만 표시' 옵션.

### 기타
- 화면 탭: 숨은 컨트롤(편집·설정·닫기), 길게 누르기: 현재 화면 사용자화
- 시스템 시각·시간대 변경 즉시 반영, 회전·다양한 화면 비율 대응, 권한을 거부해도 시계는 정상 동작
- 화면이 꺼지거나 앱이 가려지면 센서·애니메이션·구독 중지

## 6. 프로젝트 구조
```
app/src/main/java/com/galaxy/standbypro/
├─ StandByApp.kt                 저장소 컨테이너
├─ data/                         설정(DataStore), 배터리, 날씨, 캘린더, 사진
├─ music/                        외부 세션, 내부 플레이어(PlaybackService), 커버 로더, 통합
├─ system/                       충전 감지 서비스, 부팅 리시버
├─ dream/StandByDreamService.kt  화면 보호기
└─ ui/
   ├─ standby/                   StandBy 화면(위젯·시계·사진·음악·번인·야간·편집)
   ├─ settings/                  한국어 설정 화면
   └─ theme/                     색·글꼴(Inter Display)
```
